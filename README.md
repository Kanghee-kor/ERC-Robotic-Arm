# Project Overview
The ERC Robot Arm is a multidisciplianry engineering project built for the European Rover Challenge, which is an international compeitition that simulates real world Mars exploration missions. The goal is to create a 6 degree of freedom (6-DOF) arm capable of scientific tasks such as sample retrieval, object manipulation and drilling operations. All of these tasks must be successful under the weigt, rigidity and realiability constraints of a competiton rover. 

The project follows a full engineering design process: 

```text
Problem Definition
        ↓
Requirement Analysis
        ↓
Motor Selection
        ↓
Torque Analysis
        ↓
Mechanical Design
        ↓
CAD Development
        ↓
Prototype Manufacturing
        ↓
Assembly & Testing
        ↓
Final Aluminium Version
        ↓
Software Integration
        ↓
ERC Competition
```

As the Robot Arm Team Lead, I was responsible for leading the mechanical development of the arm, including motor selection, torque analysis, CAD design, manufacturing planning, technical documentation and project coordination.
